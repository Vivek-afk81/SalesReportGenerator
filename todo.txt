# CORE DS SIGNALS — LOCKED

# [x] Signal 1 : Market basket analysis
#                Products quietly bought together
#                Method : FP-Growth (mlxtend)
#                Output : Association rules with support, confidence, lift
#
# [x] Signal 2 : Stockout velocity detection  
#                Fast sellers with frequent stockout gaps
#                Method : Isolation Forest (scikit-learn)
#                Output : Per-product risk score and velocity vs restock rate
#
# [x] Signal 3 : Temporal demand anomaly
#                Categories showing unusual demand spikes by week
#                Method : Rolling mean + Z-score or STL decomposition
#                Output : Flagged weeks per category with deviation score
